This file is **curated**, not a transcript. Add what's useful for future issues; leave the session noise in `state.md`. When in doubt: would the next continent want to know this before it starts building? Then write it down.

`/ask` reads this file (and the retros) with citations, so use real section headings — they become the citation anchors.
